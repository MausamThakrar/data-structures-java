# Data Structures in Java

This project implements several classic **data structures from scratch** in Java.  
The goal is to demonstrate strong understanding of core computer science concepts,  
object-oriented design, and the internal workings of fundamental data structures.

All implementations avoid using built-in Java collection classes (except where used  
intentionally for simplicity, such as `LinkedList` inside the custom HashTable buckets).
